End-to-end analytics pipeline on 21 years of Australian overseas migration data (ABS, 2004-05 to 2024-25). Four raw ABS Excel files are cleaned and reshaped, loaded through a bronze/silver/gold medallion architecture in Databricks (Delta Lake, PySpark), modelled as a star schema, and surfaced in a 3-page AI/BI dashboard. Includes data-quality checks: a net = arrivals − departures reconciliation, subtotal handling, and a geography double-count fix.
